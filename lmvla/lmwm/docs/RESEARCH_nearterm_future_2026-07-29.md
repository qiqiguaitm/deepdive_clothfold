# 调研:近端未来提示注入 VLA 是否正确(2026-07-29, 106 agent 对抗校验)

## 判决:正确,且有清晰的使用判据
1. **Horizon 倒 U 律**(两独立工作同形):K=1 因冗余收益小(AHEAD K=1 50% vs K=5 93.8%;GR-1 Δt=1 3.61<Δt=3 3.82,作者亲述"连续帧过近似"),过长因累积误差退化(K=12 掉点)。**最优 3-7 步——我们的 t+7 正在文献甜区**(Seer/VPP 的固定值反而从未消融)。
2. **冗余≠无效,有效信息在非冗余分量**:AHEAD 只替换 motion/language-salient patch、静态 patch 明确保留当前观测("静态背景没变,当前观测就是正确预测")——**这是我们时间残差的空间版,独立收敛**。文献无人定量测过冗余度 vs 收益(我们的 86%/CV 测量是空白点)。
3. **注入形式**:唯一同架构直接对照(Seer, ICLR'25 Oral)显式条件化>纯辅助 loss(增量 2.5×),但辅助 loss 单独拿大部分收益;VPP 证明**单步去噪的粗表征即够**(2步不更好)→ 机理=预测性表征塑形+粗未来条件化,**不需要精确渲染未来**。
4. **收益分布**:动态/观测过时场景才有信息注入型收益(AHEAD 静态场景全方法打平);DEHP:接触敏感相位最优 horizon 收缩到≈1 步 → 静态桌面上 t+7 的 +6 更可能是表征塑形/接触相位细化。
5. **⚠️核心风险(同行评审级证据)**:causal confusion/copycat(NeurIPS'19/'20)——高相关条件通道可在**验证 loss 更低的同时闭环更差**;t+7 通道满足两个失效前置(专家动作时间相关+冗余可恢复)。**判据:离线指标不能认证 t+7 价值,只有变 seed 闭环 SR 可以**(反向背书我们的 eval 纪律)。
6. **文献空白=我们的机会**:①冗余度定量测量(已有);②**近端×远端 2×2 通道消融无人做过**——我们缺 ms-only 臂,补一个训练即填补空白;③自适应/相位 horizon 是 2026 趋势(支持逐状态门控方向)。

## 对我们的三个直接行动
- **A. hint 捷径探针**(零训练):推理期对 t+7/ms 通道置零/加噪,测崩塌度——防 copycat 捷径;复用 LMWM_SWAP_HINT 注入点。
- **B. ms-only 臂**(1 训练):补齐 {no-WM, t+7-only, ms-only, dual} 2×2——文献空白,ICLR 卖点级消融。
- **C. 写作弹药**:t+7 horizon 引 GR-1/AHEAD 甜区背书;AHEAD 静态 patch 保留=残差的空间同构(§related);“离线指标不可认证”引 causal confusion 支撑多 seed 闭环纪律。
